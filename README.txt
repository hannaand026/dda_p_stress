# dda_p_stress

## Code used for DDA P stress experiment analysis

'dda_p_stress_per_cell_calculations.Rmd' -- converting transcript counts to molecules per cell
'dda_p_stress_figs_stats_code.Rmd' -- sample code for figures and statistics

## Futher resources

Supplemental files and intermediate data products used for analysis are available on Zenodo (https://doi.org/10.5281/zenodo.22968423), along with supplemental figures and the supplemental fasta files.

DDA culture isolate RNA sequences are available in National Center for Biotechnology Information (NCBI) BioProject PRJNA1509514.
